

\# DocuMind AI



DocuMind AI is an intelligent document processing platform designed to classify documents and extract structured information using machine learning, deep learning, and OCR.



\## Project Objectives



\- Automated document classification

\- Intelligent information extraction

\- OCR-based document processing

\- Structured data extraction

\- Interactive document management interface



\## Technology Stack



\### Backend

\- Python 3.11

\- FastAPI



\### Machine Learning

\- PyTorch

\- Torchvision

\- Hugging Face Transformers



\### OCR and Document Processing

\- PaddleOCR

\- PyMuPDF

\- OpenCV

\- Pillow



\### Frontend

\- React

\- TypeScript

\- Vite



\### Database

\- SQLite



\### Experiment Tracking

\- MLflow
